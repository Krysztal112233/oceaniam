# OceanIAM Rust SDK

Rust client library for the [OceanIAM](/../../) API.

## Usage

```rust
use oceaniam_sdk::OceanIamClient;

let client = OceanIamClient::new("https://iam.example.com")
    .with_token_getter(|| std::env::var("OCEANIAM_TOKEN").ok());

let tenants = client.get_tenants(None).await?;
```

Applications authenticate themselves via `with_app_secret`:

```rust
let client = OceanIamClient::new("https://iam.example.com")
    .with_app_secret("sk-...");

let users = client.get_application_users("t_id", "app_id", None).await?;
```

## Authentication

Requests specify their required auth mode — `Bearer`, `AppSecret`, `BearerOrAppSecret`, or `None`.
The client picks whichever credential is available at call time.

In most cases, `AppSecret`-authenticated requests can access **application-scoped resources** (users, keys, configuration), while `Bearer`-authenticated requests (admin JWT) can also **modify application metadata** and manage cross-tenant resources.
